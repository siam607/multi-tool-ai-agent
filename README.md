# 🇧🇩 Multi-Tool AI Agent for Bangladesh

## 🎯 Project Objective
This project implements an intelligent AI Agent capable of answering specific data-driven queries about Bangladesh using local SQLite databases and general knowledge queries using web search tools. The agent is built using **LangChain** and **Python**, demonstrating proficiency in backend architecture, database management, and AI integration.

## 🛠️ Features
- **Institutional Data:** Queries about universities, colleges, and government offices.
- **Hospital Data:** Information on hospitals, bed capacity, doctors, and facilities.
- **Restaurant Data:** Details on cuisine, ratings, and locations.
- **Web Search:** Real-time information on policies, culture, and general facts using Tavily API.
